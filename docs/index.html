Quick start

Connect Coolify.

Requires Bun 1.1 or newer. Install the plugin, set connection details for the MCP process, and review Coolify's connection status.

01 / INSTALL

Install the plugin

In Codex, add this repository as a marketplace, then install the plugin.

codex plugin marketplace add https://github.com/jurislm/coolify-plugin
codex plugin add coolify-plugin@coolify-marketplace

For Cursor

Choose Import from Repo in Cursor to add this repository as a marketplace, then install Coolify Plugin. Paste this URL: https://github.com/jurislm/coolify-plugin.

02 / CONFIGURE

Set your Coolify connection

Set these variables in the environment available to the MCP process.

COOLIFY_BASE_URL=https://coolify.example
COOLIFY_ACCESS_TOKEN=your-api-token

Codex Desktop may not inherit terminal exports. Set the variables in the app environment and start a new task after changing them.

In Cursor's local Configure panel, enter the URL and token. For Cursor Cloud agents, set them in Cloud environment secrets; the README covers fallback variable names and precedence.

03 / VERIFY

Review connection status

The first tool returns the plugin version. The second reports the selected configuration and Coolify's /health and /version status without exposing credentials.

coolify_get_mcp_version
coolify_check_connection

A stdio plugin for your Coolify instance.

This repository ships a local stdio MCP plugin for Codex and Cursor. The MCP process runs in the client environment and calls the Coolify API URL you configure. It does not include a hosted MCP endpoint or OAuth flow. Submission to the OpenAI public Plugin Directory is outside this repository's scope.

快速開始

連接 Coolify。

需要 Bun 1.1 以上版本。安裝外掛、設定 MCP 程序的連線資訊，再查看 Coolify 的連線狀態。

01 / 安裝

安裝外掛

Codex：將此 GitHub repository 加入外掛市集，再安裝外掛。

codex plugin marketplace add https://github.com/jurislm/coolify-plugin
codex plugin add coolify-plugin@coolify-marketplace

使用 Cursor

在 Cursor 選擇 Import from Repo，將此 GitHub 儲存庫加入外掛市集，再安裝 Coolify Plugin。請貼上完整網址：https://github.com/jurislm/coolify-plugin。

02 / 設定

設定 Coolify 連線

在 MCP 程序可讀取的環境中設定以下變數。

COOLIFY_BASE_URL=https://coolify.example
COOLIFY_ACCESS_TOKEN=your-api-token

Codex 桌面版不一定會繼承終端機匯出的環境變數；請在 Codex 應用程式環境中設定，變更後另開新任務。

Cursor 本機版可在 Configure 面板填入網址與 token；Cursor Cloud agents 請在 Cloud environment secrets 中設定。備援變數名稱與優先順序見 README。

03 / 驗證

檢視連線狀態

第一個工具回報外掛版本；第二個回報所選設定與 Coolify 的 /health、/version 狀態，且不會顯示憑證。

coolify_get_mcp_version
coolify_check_connection
