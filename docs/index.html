Three steps

Get connected.

Install the plugin, configure the Coolify connection, then make a read-only check.

01 / INSTALL

For Codex

Add the Coolify marketplace and install its plugin.

codex plugin marketplace add https://github.com/jurislm/coolify-plugin
codex plugin add coolify-plugin@coolify-marketplace

For Cursor

Open Customize → Plugins → Add Marketplace → Import from GitHub and enter this repository.

02 / CONFIGURE

Set your Coolify connection

Use your instance URL and API token in the client configuration.

COOLIFY_BASE_URL=https://coolify.example
COOLIFY_ACCESS_TOKEN=your-api-token

In Cursor, you can also enter both values in the plugin's Configure panel.

03 / VERIFY

Check the connection

Call the version tool, then check that the configured Coolify instance responds.

coolify_get_mcp_version
coolify_check_connection

A local plugin for your own Coolify.

This project is a local stdio MCP plugin for Codex and Cursor. It is not a hosted service, does not provide OAuth, and is not listed in the OpenAI public Plugin Directory. Your client runs the plugin and connects to the Coolify instance you configure.

三個步驟

開始連線。

安裝 plugin、設定 Coolify 連線，再執行唯讀檢查。

01 / 安裝

使用 Codex

新增 Coolify marketplace 並安裝 plugin。

codex plugin marketplace add https://github.com/jurislm/coolify-plugin
codex plugin add coolify-plugin@coolify-marketplace

使用 Cursor

開啟 Customize → Plugins → Add Marketplace → Import from GitHub，並輸入此 GitHub repository。

02 / 設定

設定 Coolify 連線

在用戶端設定中填入執行個體網址與 API token。

COOLIFY_BASE_URL=https://coolify.example
COOLIFY_ACCESS_TOKEN=your-api-token

在 Cursor 也可以透過 plugin 的 Configure 面板填入這兩項設定。

03 / 驗證

檢查連線

先呼叫版本工具，再確認設定的 Coolify 執行個體有回應。

coolify_get_mcp_version
coolify_check_connection
